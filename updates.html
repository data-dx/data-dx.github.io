2027 年發展目標

  1. 工具發展：
    • InfoRec：持續支援與強化各類文件、表單的資訊紀錄蒐集，讓蒐集到的資訊成為可再運用的資源。
    • IRVault：已於 Solana dApp Store 上架，持續強化虛擬資產管理的相關應用。網頁版因瀏覽器的安全限制，暫時無法使用幣安等交易所的 API Key，需要時請使用 App 版。
  2. 使用說明完善： 持續更新使用指南與教學，讓使用者能快速上手。
  3. 多國語言： 目前已內建 24 種語系，並依使用者需求持續擴充與校對。
  4. 社群交流與互助： 歡迎在社群群組分享使用心得與應用經驗，透過交流與互助，讓工具的應用持續成長。
