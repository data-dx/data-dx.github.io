把資訊與資產管理，做得務實而可控

InfoRec Labs 是個人的軟體開發專案，開發實用的資訊管理與數位資產管理工具，讓使用者自行掌控資訊與資產。

  • InfoRec：Windows 桌面工具，用來整理文件紀錄、套印表單，把資訊紀錄確實數位化，成為使用者可以再運用的資源。隱私權政策
  • IRVault：Solana Mobile 手機 App 與網頁版，非託管的資產管理工具。可用錢包地址或交易所 API Key 整合查看虛擬資產，支援 Solana、BNB Chain、Ethereum 的轉帳以及代幣交換。隱私權政策
