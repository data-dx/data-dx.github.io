IRVault 虛擬資產管理工具

IRVault 是非託管的虛擬資產管理工具，協助您整合所有錢包、地址與交易平台上的虛擬資產，並在同一處完成傳送、接收與交換。

如何取得 IRVault

  • Solana Mobile 手機：在 Solana dApp Store 搜尋並安裝 IRVault。
  • 一般手機與電腦：使用瀏覽器開啟網頁版 app.inforec.dev。

軟體核心功能

IRVault 將散落在多個錢包與平台上的虛擬資產整合在一起，不必在各個 App 之間切換、適應不同的畫面與操作，可以提升使用體驗，並提供以下特點：

  • 多鏈傳送與交換：Solana、BNB Chain、Ethereum 上的資產都可以傳送與交換。
  • 接收：不限幣種，依收款地址支援，例如 BTC、DOGE、TRX。
  • 顯示交易平台資產：目前支援幣安唯讀 API Key（App 版），可顯示帳戶資產，也可接收資產（僅限 BNB Chain）。
  • 資產交換：Solana 串接 Jupiter 自動找最佳路徑，支援市價與限價；BNB Chain、Ethereum 可透過多鏈錢包進行市價交換。
  • 管理錢包軟體：IRVault 不是錢包軟體，不存取助記詞與私鑰，傳送或交換都由您現有的錢包完成。
  • InfoRec 註冊：InfoRec 資訊紀錄管理工具可透過 IRVault 線上註冊，註冊後可取得軟體更新，並使用相關進階功能。
  • IREC 憑證：
    1. 推廣與鼓勵：憑證可以解鎖 InfoRec 資訊紀錄管理工具更多功能，並鼓勵使用者多加運用 InfoRec。
    2. 領取憑證：使用 Solana Mobile 手機、完成 InfoRec 註冊，或對 InfoRec 推廣有貢獻的人，都可以領取 IREC 憑證。
備註：為了讓 IRVault 操作更快、更穩定，請務必申請免費的 Helius 與 Jupiter API Key，申請方式請見系統設定 → API Key。

IRVault 架構

IRVault
↑ 傳送 Solana、BNB Chain、Ethereum ↓ 接收 依收款地址支援 ⇄ 交換 Solana、BNB Chain、Ethereum ✦ 系統設定 安全防護、API Key

錢包與地址

  • 加入錢包與地址：把您所有的錢包與資產地址加進來集中管理，依需要可以進行傳送、接收及交換資產。
  • 如要顯示幣安帳戶（限 IRVault App 使用），申請方式請見 API Key。

資產總覽

  • 整合呈現：把您加入的錢包、地址與交易平台上的資產集中在同一個畫面，可以整合顯示，也可以個別查看。

代幣列表

  • 呈現重要資產：隱藏小額資產與詐騙幣，避免干擾，只呈現您想看的重點資產。

傳送

  • 區塊鏈支援：Solana、EVM 鏈（BNB Chain、Ethereum，可透過如 OKX Wallet 等多鏈錢包）。
  • 選擇錢包、地址：「錢包與地址」可以管理您所有的錢包及資產地址，加入後傳送方與收款方都能直接選取，降低傳錯的風險。
  • 資產地址格式檢查：地址與所選區塊鏈不符時，會以紅字提示且無法傳送；但格式正確不代表地址一定對，送出前仍請自行確認。
  • 錢包簽署：傳送、交換等操作都不會存取您的私鑰，所有交易都由您的錢包簽署。
送出後無法撤銷：傳送、交換、掛單都是鏈上交易，送出前請確認地址與金額；大額傳送前，建議先用小額測試一次。

接收

  • 接收資產：用已加入的錢包地址產生收款 QR Code，對方掃描就能轉入，降低地址錯誤的風險。
  • 不限幣種：無論是 BTC、DOGE、TRX 或其他虛擬貨幣，只要有該幣的收款地址就能收取。

交換

  • 自動找最佳路徑：Solana 鏈串接 Jupiter，自動比較各交易管道的報價，找出最划算的換法，避開交易量太小、價格容易偏移的路線。
  • 市價與限價：Solana 可用市價立即交換，也可以自己設定價格掛限價單；BNB Chain、Ethereum 可透過多鏈錢包進行市價交換。
  • 保留適當手續費：把 SOL 全部換出時，會自動留下一點 SOL 支付網路手續費，避免帳戶之後無法再交易。
  • 自訂交易滑點：可依需要調整滑點容忍度（可接受的價格偏差）：設小一點可減少價格偏差，設大一點較容易成交。

交易記錄

  • 歷史記錄查詢：查看 Solana 錢包、地址的交易記錄，點選任一筆可查看鏈上資料（目前僅支援 Solana 鏈）。
  • 完整記錄：請申請並設定免費的 Helius API Key，以利取得完整的交易記錄。

一般

  • 語言：選擇 IRVault 畫面顯示的語言。
  • 介面主題：跟隨系統、深色、一般三種；「跟隨系統」會依手機的深色／淺色模式自動切換。
  • 字體大小：標準、大字體、最大字體三種，放大小字比較好閱讀。
  • 漲跌顏色：可選「綠漲紅跌」（加密貨幣常用）或「紅漲綠跌」（臺灣等東亞股市習慣）。
  • 隱藏小額資產門檻：設定一個美元金額，在首頁勾選「隱藏小額資產」時，價值低於這個金額的代幣就不顯示。
  • 行情即時更新：設定資產多久更新一次，可從 5 秒到 10 分鐘（預設 15 秒）。

安全與資料

  • 安全：可設定登入密碼、指紋辨識（生物辨識）或 Google Authenticator 來保護 IRVault。詳見安全與錢包。
  • 註冊：註冊後可以收到我們推送的訊息。需要先連接錢包並簽名一次，確認地址是您的（簽名不花手續費）。
  • 資料備份與還原：換版本或重新安裝 App 前，建議先備份本機資料（通訊錄、代幣顯示設定等）。備份檔會用您設定的密碼加密，還原時要輸入相同密碼。

進階連線

  • 區塊鏈節點介接：填入 Helius 與 Jupiter API Key。請務必申請這兩個免費的 API Key，讓操作更快、更穩定。詳見API Key。
  • 交易平台介接（限 IRVault App 使用）：填入幣安唯讀的 API Key、Secret，並設定本機防護密碼（至少 6 位數），就能顯示幣安帳戶資產。詳見API Key。

InfoRec 註冊

  • InfoRec 資訊紀錄管理工具可透過 IRVault 線上註冊，註冊後可取得軟體更新，並使用相關進階功能。

領取 IREC

  • 推廣與鼓勵：IREC 憑證可以解鎖 InfoRec 資訊紀錄管理工具更多功能，並鼓勵使用者多加運用 InfoRec。
  • 誰可以領取：使用 Solana Mobile 手機、完成 InfoRec 註冊，或對 InfoRec 推廣有貢獻的人，都可以在 IRVault 領取 IREC 憑證。

安全防護

您可以依需要選擇自訂密碼、Google Authenticator 二次驗證、生物辨識（指紋）來提升資訊安全。

使用前，您該知道的事

  • IRVault 不保管您的資產：IRVault 不是交易所，不持有、也不保管您的任何資產。畫面上的餘額，是依您在「錢包與地址」加入的錢包或地址，即時向區塊鏈與交易平台查詢而來。但 IRVault 可以搭配您的錢包進行傳送與交換，這些操作會動用您的資產，因此建議開啟上方的安全防護。

API Key 申請說明

為了讓 IRVault 操作更快、更穩定，請務必申請免費的 Helius 與 Jupiter API Key；幣安 API Key 則依需要申請。申請後到 IRVault 的【系統設定】填入即可。

Helius API Key

請至 helius.dev 免費申請。此 API Key 可讓 Solana 鏈上資產查詢更快、更完整，避免使用公用節點造成回應緩慢及延遲的問題。

Jupiter API Key「One API Key」

請至 portal.jup.ag 免費申請。讓 Solana 交換報價與掛單更順暢，未申請可能會跳出「請求過於頻繁」的提示。

幣安 (Binance) API Key（限 IRVault App 使用）

請至幣安免費申請，因目前 IRVault 僅可唯讀顯示幣安帳戶的資產，因此建立 API Key 時只需勾選「讀取」權限，不必開啟交易或提領權限。
