IRVault 虛擬資產管理工具

IRVault 是非託管的虛擬資產管理工具，協助您整合所有錢包、地址與交易平台上的虛擬資產，並在同一處完成傳送、接收與交換。

如何取得 IRVault

  • Solana Mobile 手機：在 Solana dApp Store 搜尋並安裝 IRVault。
  • 一般手機與電腦：使用瀏覽器開啟網頁版 app.inforec.dev。

軟體核心功能

IRVault 將散落在多個錢包與平台上的虛擬資產整合在一起，不必在各個 App 之間切換、適應不同的畫面與操作，可以提升使用體驗，並提供以下特點：

  • 多鏈傳送與交換：Solana、BNB Chain、Ethereum 上的資產都可以傳送與交換。
  • 接收：不限幣種，依收款地址支援，例如 BTC、DOGE、TRX。
  • 顯示交易平台資產：目前支援幣安唯讀 API Key（App 版），可顯示帳戶資產，也可接收資產（僅限 BNB Chain）。
  • 簡易交換：Solana 串接 Jupiter 自動找最佳路徑，支援市價與限價；BNB Chain、Ethereum 透過多鏈錢包交換。
  • 管理錢包軟體：IRVault 不是錢包軟體，不存取助記詞與私鑰，傳送或交換都由您現有的錢包完成。
  • InfoRec 註冊：InfoRec 資訊紀錄管理工具可透過 IRVault 線上註冊。
  • IREC 憑證：
    1. 推廣與鼓勵：憑證可以解鎖 InfoRec 資訊紀錄管理工具更多功能，並鼓勵使用者多加運用 InfoRec。
    2. 領取憑證：使用 Solana Mobile 手機、完成 InfoRec 註冊，或對 InfoRec 推廣有貢獻的人，都可以領取 IREC 憑證。
備註：為了讓 IRVault 操作更快、更穩定，請務必申請免費的 Helius 與 Jupiter API Key，申請方式請見輔助功能 → API Key。

IRVault 架構

IRVault
↑ 傳送 Solana、BNB Chain、Ethereum ↓ 接收 依收款地址支援 ⇄ 交換 Solana、BNB Chain、Ethereum ✦ 輔助功能 安全與錢包、API Key

【傳送】功能說明

  • 區塊鏈支援：Solana、BNB Chain、Ethereum（EVM 鏈透過多鏈錢包）。
  • 選擇錢包、地址：「錢包與地址」可以管理您所有的錢包及資產地址，加入後傳送方與收款方都能直接選取，降低傳錯的風險。
  • 資產地址格式檢查：地址與所選區塊鏈不符時，會以紅字提示且無法傳送。
  • 錢包簽署：透過您現有的錢包簽署，避免私鑰外洩。
送出後無法撤銷：傳送、交換、掛單都是鏈上交易，送出前請確認地址與金額；大額傳送前，建議先用小額測試一次。

【接收】功能說明

  • 收款 QR Code：先選取錢包與接收的資產（如 SOL），就會產生收款地址的 QR Code，掃描即可轉入。
  • 不限幣種：依收款地址支援，可收取 BTC、DOGE、TRX 等虛擬貨幣。

【交換】功能說明 (Swap)

  • SOL鏈最優路徑下單：串接 Jupiter 聚合協議，精算全網 AMM 與訂單簿深度，自動避開低流動性幣對降滑點。
  • 最低到手保證 (Minimum Received)：清楚標示扣除滑點後的最低到手數量，降低 MEV 機器人夾單的風險。
  • 防零餘額卡死機制：換出全部 SOL 時系統自動預留基礎 Gas 費，確保帳戶後續可正常交互。
  • 自訂交易參數：支援使用者依需求彈性設定滑點容忍度（Slippage）與加速優先手續費（Priority Fee）。

【輔助功能】說明

  • 垃圾幣與資產自訂隱藏：可手動勾選隱藏釣魚代幣或低流動性資產，保持首頁清爽只留重要持倉。
  • 合約地址 (CA) 檢驗：展開幣種卡片可直接檢驗真實鏈上合約地址，避免誤入同名貔貅盤（Honeypot）陷阱。
  • 交易所唯讀整合 (BYOK)：支援自備唯讀的 API Key 讀取幣安現貨與理財餘額，金鑰僅儲存於您的設備本地。
  • 自訂 RPC 節點切換：支援切換私人節點端點以提升網路壅塞時的載入速度與穩定度。

安全防護（3 種密碼設定）

為防止身旁他人窺探您的資產餘額或進行未授權操作，使用者依需要選擇：自訂密碼、Google Authenticator 二次驗證、生物辨識 / 指紋 等 3 種防護功能。

使用前，你該知道的事

  • IRVault 是儀表板，不是交易所：它不持有、不保管您的任何資產。畫面上看到的餘額都是您自行在「錢包與地址」連接的錢包或(自己)地址，即時向鏈上節點與交易所 API 查詢而來，IRVault 所有的設定、記錄只存在您的設備之中，助記詞與私鑰永遠只留在您自己的錢包裡。
  • 每個錢包彼此嚴格獨立：切換不同錢包或地址時，資料是各自獨立讀取，不會互相借用或混合快取。

常見金鑰 (API Key) 申請簡介

以下都是「選填」項目，不申請也能正常使用 IRVault，只是部分體驗會打些折扣，設定入口都在【系統設定】頁面內。

Helius API Key（免費）

用來加速 Solana 鏈上資產查詢的速度與完整度。不填的話會自動改用公共節點，能正常運作，只是速度較慢、尖峰時段偶爾會有資料延遲。可至 helius.dev 免費註冊取得。

Jupiter API Key「One API Key」（免費）

用來提高 Swap 報價與網格掛單的請求速率上限，避免忙碌時段跳出「請求過於頻繁」的提示。可至 portal.jup.ag 免費申請。

幣安 (Binance) API Key

如果您想讀取您幣安帳戶的資產餘額，目前僅提供唯讀顯示，申請時請務必只勾選「讀取」權限。
