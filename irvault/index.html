IRVault 數位資產管理工具-功能入門說明

IRVault 是一款專為區塊鏈使用者打造的 純前端、非託管（Non-Custodial）跨鏈資產儀表板。落實「Not your keys, not your coins」核心原則，助您將掌控的錢包、地址，一站式搞定多鏈資產盤點、極速 DEX Swap 與安全轉帳。

一 軟體核心功能

可整合多種錢包、各種鏈上地址、交易平台的資產，避免在多個虛擬貨幣 APP 間頻繁來回切換的割裂體驗，提供三大優勢：

  • 多鏈資產一站式聚合：同步讀取多鏈錢包（如 Solana Seeker Wallet、OKX Wallet、Phantom）、獨立地址（例如 BTC、DOGE 地址）與交易平台（如幣安），以即時匯率折算為 USD 淨值，告別手動記帳。
  • 100% 本地非託管架構：有錢包或地址即可顯示資產；傳送或交換時經由個人錢包授權執行，完全不存取助記詞與私鑰。
  • 聚合原生 Swap 深度：直接串接 Solana 最大 DEX 聚合協議 Jupiter，以最佳可用路徑進行 SOL 鏈市價或限價交換。

二 安全防護（3 種密碼設定）

為防止身旁他人窺探您的資產餘額或進行未授權操作，使用者依需要選擇：自訂密碼、Google Authenticator 二次驗證、生物辨識 / 指紋 等 3 種防護功能。

三 IRVault 首頁與功能架構

啟動後的預設主畫面，即時掌握合併、或指定錢包、地址顯示資產的持倉價值，並具備傳送、接收、交換及輔助功能等 4 項功能。

1

【傳送】功能說明

  • 本地專屬通訊錄：由錢包管理加入的錢包，具備傳送的條件，輕鬆切換錢包，快速選取已連接的錢包、地址、平台，降低傳送錯誤地址的風險，降低人為風險確保資產安全。
  • 跨鏈地址格式防呆：選定公鏈發送時若貼入錯誤鏈種地址，系統即時提示紅字並禁止點擊發送。
  • 純本地簽章授權：所有交易均直接調用本機授權錢包進行簽署與廣播，私鑰絕不上傳。
  • 鏈上交易一旦送出就無法撤銷：傳送、交換、掛單都是真實上鏈的動作，請務必先確認地址與金額無誤，建議大額操作前先用小額測試過一次。
2

【接收】功能說明

  • 專屬收款 QR Code：簡易切換錢包，快速選取接收的資產，自動產生收款地址條碼，方便掃描快速入帳。
  • 多鏈標籤分類管理：支援為不同公鏈或用途地址自訂歸類標籤，方便日後統計與對帳。
3

【交換】功能說明 (Swap)

  • SOL鏈最優路徑下單：串接 Jupiter 聚合協議，精算全網 AMM 與訂單簿深度，自動避開低流動性幣對降滑點。
  • 最低到手保證 (Minimum Received)：清楚標示扣除滑點後的最低到手數量，降低 MEV 機器人夾單的風險。
  • 防零餘額卡死機制：換出全部 SOL 時系統自動預留基礎 Gas 費，確保帳戶後續可正常交互。
  • 自訂交易參數：支援使用者依需求彈性設定滑點容忍度（Slippage）與加速優先手續費（Priority Fee）。
4

【輔助功能】說明

  • 垃圾幣與資產自訂隱藏：可手動勾選隱藏釣魚代幣或低流動性資產，保持首頁清爽只留重要持倉。
  • 合約地址 (CA) 檢驗：展開幣種卡片可直接檢驗真實鏈上合約地址，避免誤入同名貔貅盤（Honeypot）陷阱。
  • 交易所唯讀整合 (BYOK)：支援自備唯讀的 API Key 讀取幣安現貨與理財餘額，金鑰僅儲存於您的設備本地。
  • 自訂 RPC 節點切換：支援切換私人節點端點以提升網路壅塞時的載入速度與穩定度。

四 使用前，你該知道的事

  • IRVault 是儀表板，不是交易所：它不持有、不保管您的任何資產。畫面上看到的餘額都是您自行在「錢包與地址」連接的錢包或(自己)地址，即時向鏈上節點與交易所 API 查詢而來，IRVault 所有的設定、記錄只存在您的設備之中，助記詞與私鑰永遠只留在您自己的錢包裡。
  • 每個錢包彼此嚴格獨立：切換不同錢包或地址時，資料是各自獨立讀取，不會互相借用或混合快取。

2 常見金鑰 (API Key) 申請簡介

以下都是「選填」項目，不申請也能正常使用 IRVault，只是部分體驗會打些折扣，設定入口都在【系統設定】頁面內。

Helius API Key（免費）

用來加速 Solana 鏈上資產查詢的速度與完整度。不填的話會自動改用公共節點，能正常運作，只是速度較慢、尖峰時段偶爾會有資料延遲。可至 helius.dev 免費註冊取得。

Jupiter API Key「One API Key」（免費）

用來提高 Swap 報價與網格掛單的請求速率上限，避免忙碌時段跳出「請求過於頻繁」的提示。可至 portal.jup.ag 免費申請。

幣安 (Binance) API Key

如果您想讀取您幣安帳戶的資產餘額，目前僅提供唯讀顯示，申請時請務必只勾選「讀取」權限。
